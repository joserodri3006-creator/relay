# Blazed Outfitters — Pilot

Blazed Outfitters ist die erste Pilotmarke von Relay. Das betreibende
Unternehmen ist **R&C Lifestyle**.

## Bekannter Kommunikationsumfang

| Kanal | Konten |
| --- | ---: |
| E-Mail | 4 Postfächer |
| Instagram | 3 Accounts |
| TikTok | 1 Account |
| **Gesamt** | **8 Endpunkte** |

## Aktivierungsstrategie

Der Pilot beginnt kontrolliert mit **einem E-Mail-Postfach**. Nach erfolgreichem
Shadow Run werden die drei weiteren Postfächer schrittweise aktiviert. Instagram
und TikTok bleiben zunächst im Integrations-Backlog, bis API-Zugang, Berechtigungen
und Nachrichten-Synchronisation pro Plattform verifiziert sind.

Diese Reihenfolge reduziert Betriebsrisiken, ohne das langfristige
kanalunabhängige Kommunikationsmodell zu verändern.

## Noch benötigte Kundendaten

- Name und Provider jedes E-Mail-Postfachs
- Auswahl des ersten Pilot-Postfachs
- Namen/Handles der drei Instagram-Accounts
- Name/Handle des TikTok-Accounts
- Ansprechpartner für Freigaben und Eskalationen
- Teammitglieder, Rollen und gewünschte Antwortzeiten
- Datenschutz-/Löschfristen und bevorzugte Hosting-Region
- gewünschter Starttermin für den Shadow Run

Zugangsdaten, Tokens und Passwörter gehören niemals in dieses Repository.
